Insert a minimum search layout onto the canvas with the required custom attributes.

Search layout

Select a parent element on the canvas (or the Body), then insert the layout. Credentials come from Install search on site in the Talaash dashboard (Custom Code API) — this panel only adds Designer elements and attributes.

After insert

  1. Style the input and result card in the Designer.
  2. In Talaash Setup, run Install search on site (if you have not already).
  3. Publish the site.
